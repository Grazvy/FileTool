# File Tool

A local file processing application that runs entirely on your machine for maximum privacy.

## Features

- Local file processing (no data sent to external services)
- Web-based interface for easy access
- Support for various file formats (PDF, images, documents)
- Batch processing capabilities

## Quick Start

1. Install Python 3.8+
2. Install dependencies: `pip install -r backend/requirements.txt`
3. Run the launcher: `python launcher/main.py`
4. The browser will open automatically

## Development

- Backend: Flask application in `backend/`
- Frontend: Static HTML/CSS/JS in `frontend/`
- Launcher: Python script to start server and open browser
